## 1. 为什么创造 igit：跳跃思维者的认知减负系统

### 1.1 物理空间与思维流动的错位

作为日常管理海量代码仓库的工程师，思考方式往往是**非线性、跳跃性且由突发念头驱动**的。例如：
- 正在写功能 A，脑中突然浮现：“上周在另一个业务库里好像写过类似的加解密实现，叫什么名字来着？”
- 临下班前突然闪过一个念头：“今天到底在哪些分支上改动了代码还没推上去？”

在传统的操作系统与开发环境中，要响应这些念头，你必须：
1. 唤出终端或打开文件管理器；
2. 在深达四五层、跨越不同磁盘（`D:\`、`E:\`）的物理路径中摸索；
3. 或者打开重型的 Git GUI 客户端，在长长的仓库列表里翻找。

**这种摩擦是致命的**。在翻找目录、回忆文件夹命名、等待界面加载的过程中，新的琐碎信息不断涌现，**最初那个珍贵的念头极易被打断，甚至彻底遗忘，最终迷失在复杂死板的文件系统路径迷宫中**。

### 1.2 破局：三大核心运作支柱

`igit` 彻底重构了人与本地代码资产的交互方式，建立起一套契合跳跃思维的完整闭环：

```
                    ┌────────────────────────┐
                    │ 1. 动态语义空间漫游    │
                    │   (维度直达 / 标签漏斗) │
                    └───────────┬────────────┘
                                │ 锁定目标单仓
                                ▼
                    ┌────────────────────────┐
                    │ 2. 原位行动与工具接力  │
                    │   (tig / 同步 / 提交)  │
                    └───────────┬────────────┘
                                │ 随手治理与屏蔽
                                ▼
                    ┌────────────────────────┐
                    │ 3. 低负荷标定治理      │
                    │   (group / tag / hide) │
                    └────────────────────────┘
```

1. **空间跃迁（Dynamic Semantic Space）**：
   将仓库从死板的磁盘物理路径中解放出来，映射到由**分组（Group，业务归属）**与**标签（Tag，多维属性）**构成的动态空间。你不再需要记住仓库究竟在 `D:\work\repos\backend\...` 还是 `E:\codes\...`，只需凭借念头中的业务名或标签（如 `group:支付`、`tag:重构中`），直接穿梭命中。
2. **原位行动闭环（In-situ Execution & Tool Escalation）**：
   一旦通过念头锁定了仓库，后续操作就应当在当前上下文就地闭环。无论是查看改动、小步提交、多远端同步，还是顺滑唤起更专业的工具（如 `tig`、资源管理器），都在原地瞬间完成，无需复制路径，无需重新打开窗口输入参数。
3. **低负荷标定治理（Effortless Triage & Governance）**：
   动态语义空间不是凭空产生的，需要持续的标定与维系。`igit` 确保治理过程具备**最低心智负担**：想做什么就敲什么动词，不记参数时自动弹出交互式编号菜单；对不关心的噪音目录一键 `hide` 或 `fold`，一次表态，永久免打扰。

### 1.3 三条基础交互法则

在使用 `igit` 的任何时刻，请牢记以下三条法则，你将不再需要查阅繁琐的参数手册：

* **法则一：空间即上下文（Scope Inference）**  
  你当前身处的位置决定了命令的操作对象。停在单仓，所有动作直接针对当前单仓；停在目录或逻辑分组，所有查询与操作自动收敛在该范围内。
* **法则二：动词即意图（Intent-Driven Fallback）**  
  命令就是你想做的事情（如 `group`、`tag`、`tig`、`export`、`push`）。当你只输入动词而没有给出后续参数时，系统**绝不报错**，而是自然弹出带编号与快捷键的交互菜单，引导你轻松完成。
* **法则三：事实与治理分离（Fact vs. Conclusion）**  
  底层 Git 的分支、提交、脏改动是“客观事实”；你的分组、标签、备注是“主观结论”。无论你全盘重新扫描多少次，已经梳理好的分组与标签**绝对不会被冲掉**。

## 2. 穿梭动态空间：随念而动的维度漫游

运行 `igit` 即可步入交互式会话。在会话中，你拥有超越物理文件系统的四维漫游能力。

### 2.1 走进作用域：cd 的多维视角

在交互终端中，`cd` 不仅可以走进物理文件夹，还可以直接走进任何逻辑维度：

```text
igit [root · 128 个仓库] > cd group:核心业务     :: 按业务念头走：直接走进「核心业务」分组
igit [group:核心业务 · 12 个仓库] > cd tag:重构   :: 交叉下钻：再叠加上「重构」标签
igit [file:D:\repos\order] -> [repo:order] >     :: 走进具体单仓
```

* **原路返回**：`cd ..` 返回上一层来时路。
* **快速来回切换**：`cd -` 在最近两个作用域之间来回跳转（例如在业务组和具体单仓之间）。
* **瞬间归零**：`cd /` 一键重置，回到全局全集视野。

### 2.2 把握当下：ls 与 pwd

无论你在多深的逻辑或物理作用域下，输入 `pwd` 和 `ls` 即可瞬间获知当前全貌：

* **`pwd`**：清晰打印你当前所在的节点类型（根、目录、分组、标签、单仓）以及完整的**来时路（Trail Stack）**。
* **`ls`**：就地呈现当前作用域下的直属子项。
  - 会输出子项所属的分组与标签；
  - 实时反映底层 Git 客观状态：分支名、脏改动标记（`*`）、领先/落后提交数。

### 2.3 念头筛选：lsbytag 响应式标签漏斗

当你脑海中只有一个模糊的属性印象，或者想通过多个标签组合快速过滤仓库时，敲入：

```cmd
lsbytag
```

系统会就地展开**响应式多维分面标签漏斗**：
1. 界面列出当前可用的全部标签及对应的关联仓库计数；
2. 支持输入标签编号进行多选（如输入 `1 3` 同时锁定两个标签）；
3. 列表会即时收缩并高亮满足条件的候选仓库；
4. 直接输入目标仓库编号，即可瞬间 `cd` 穿梭进入该仓库，完成思维到行动的无缝跨越。

### 2.4 空间全景：tree 目录骨架

如果你想从物理空间维度查看仓库在大盘上的分布密度：

```cmd
tree
```

终端将按磁盘目录层级展示仓库分布骨架与数量汇总。只有一层子节点的目录会自动合并，直观展示哪些目录下仓库最密集，避免冗长的空目录链路干扰视线。

## 3. 原位行动闭环：单仓即刻推进与专业接力

一旦通过动态空间定位到了具体仓库（提示符显示为 `[repo:xxx]`），你便进入了“单仓聚焦模式”。

### 3.1 单仓聚焦的隐式推断原则

此时，**你不需要也不能再重复输入仓库名字**。所有动作默认对准眼前的这个仓库：
- 想打开？敲 `open`；
- 想看改动？敲 `tig`；
- 想提交？敲 `commit`；
- 想推送？敲 `push`；
- 想归类？敲 `group`；
- 想打标？敲 `tag`。

### 3.2 专业工具接力：tig 智能开屏与 open 资源管理器

`igit` 的定位是“高效漫游与资产治理”，而细粒度的代码比对和复杂合并应当无缝移交给最专业的工具。

#### ① tig 智能开屏
在单仓节点下直接敲入：
```cmd
tig
```
系统会瞬间调起外部独立终端窗口启动 `tig`。`igit` 具备**状态感知开屏机制**，无需你先想该打开什么视图：
- **若当前有未提交改动** $\to$ 自动以 `status` 暂存区视图开屏，直接审阅代码差异；
- **若领先远端有未推送提交** $\to$ 自动定位到未推送提交的差异日志；
- **若尚未配置远端或是全新仓库** $\to$ 自动开在 `refs` 视图；
- **若为干净常态** $\to$ 默认开在主提交历史树。

#### ② open 资源管理器直达
在单仓节点下直接敲入：
```cmd
open
```
系统会立即调起 Windows 资源管理器打开该仓库所在的实际物理目录，方便进行文件拖拽、IDE 关联或本地操作。

### 3.3 原位轻量推进：commit 与 ignore

当你在当前仓库进行了一些微调，希望快速保存进度时：

* **`commit`**：快速就地提交。
  - 直接敲 `commit` 会提示你输入提交说明，若工作区有未暂存文件，会自动完成暂存并执行提交；
  - 亦可直接敲 `commit 修复配置解析逻辑` 快速完成。
* **`ignore`**：免语法记忆追加忽略规则。
  - 敲入 `ignore`：打印当前仓库的 `.gitignore` 内容；
  - 敲入 `ignore add`：自动提取工作区当前的未跟踪文件作为候选项（支持 Tab 补全），选择即可自动追加进 `.gitignore`，不再需要手动编辑文件。

### 3.4 远端无密协同：remote、fetch、pull 与 push

`igit` 内置了一套轻量且具备安全防护的 GitOps 动作链，凭证统一经由本地 Windows DPAPI / AES-256-GCM 安全加密存储：

* **`remote`**：远端管理中心。直接敲 `remote` 即可查看当前仓库绑定的全部远程地址与授权账号；支持免密码交互式配置/更新 Token。
* **`fetch`**：抓取最新远端。单远端直接同步；多远端默认并发全量抓取。
* **`pull`**：快进同步。多远端时弹出单选菜单；**两端分叉预检保护**：若检测到本地与远端历史发生冲突分叉，会自动提前拦截并明确提醒，绝不暗中执行破坏性 merge。
* **`push`**：推送到远端。多远端时弹出交互式复选框（支持空格多选、`a` 全选），勾选后一键并发透传 Token 免密推送。

### 3.5 原位体检与查重：stats 与 dupes

* **`stats`**：在单仓下敲 `stats`，直接输出当前仓库的全息体检卡片：
  - 分支、HEAD 状态、最新提交时间与作者；
  - 暂存区、工作区、未跟踪改动文件数明细；
  - 与远端分支的超前/落后状态；
  - 所属分组、已有标签、备注信息。
* **`dupes`**：在单仓下敲 `dupes`，**即刻以当前仓库为基准，排查全盘是否存在相同源地址的重复克隆副本**。若有，列出对应目录与最后提交时间，方便你清理多余磁盘占用。

## 4. 低负荷标定治理：维系动态空间的秩序

为了让动态语义空间保持高效，标定操作必须具备极高的交互顺畅度。

### 4.1 group：单一排他业务归属 ($N:1$)

一个仓库在业务上只应属于一个主归属分组（例如“核心业务”、“基础设施”或“个人实验”）。

#### ① 单仓就地划定（停在单仓节点时）
- 直接敲 `group`：终端就地弹出分组选择菜单：
  ```text
  仓库: order-service (当前分组: 未分组)
     1) [√] 核心业务
     2)     基础设施
     3)     归档实验
     +) [新建分组...]
     0) [清除分组]
  请选择 (编号 / + / 0 / q 取消): 1
  ```
- **唯一性替换二次确认**：若当前仓库已归属其他组，变更时系统会显式提示 `确认变更为 [基础设施]? [y/N]`，回车即安全取消，防止手滑破坏既有秩序。

#### ② 目录与全集批量划定（停在目录或根作用域时）
当你面对一个目录下的一批仓库时，无需逐仓执行：
- 直接敲 `group`：系统自动识别当前所处的目录范围，展开**当前作用域专属的分组批量管理向导**；
- 支持光标移动、空格多选目标仓库，一键将当前目录下的这批仓库批量划入指定分组。

### 4.2 tag：自由多重属性打标 ($N:M$)

与分组的排他性不同，标签是自由的多维属性标记（如 `待重构`、`临时备份`、`Go`、`Python`）。

#### ① 单仓复选打标（停在单仓节点时）
直接敲 `tag`，呼出带勾选框的多选面板：
```text
仓库: order-service (当前标签: Go)
现有标签 (输入编号切换勾选，支持多个编号用空格隔开):
   1) [√] Go
   2) [ ] 待重构
   3) [ ] 关键服务
   +) [新建标签...]
   0) [清空所有标签]
请选择 (编号 / + / 0 / q 完成退出): 2
已更新 order-service 标签: Go, 待重构
```
- 输入 `2` 即可直接将该标签打上；支持输入多个编号（如 `1 3`）批量翻转勾选状态。
- 亦支持直通指令：`tag add 待重构`、`tag rm 待重构` 或 `tag clear`。

#### ② 标签作用域下的批量脱敏（停在 tag:<标签名> 节点时）
当你在 `tag:待重构` 作用域下完成代码改造后：
- 敲 `tag rm`：系统会把该标签下的仓库编号列出，输入序号即可直接剥离标签。

### 4.3 note：单仓轻量备忘

有时你想记下一句话说明（例如为什么这个仓库暂时不动、等待谁的联调）：
- `note 需等待网关上线后再进行改造`：记录一条备注；
- `note`：查看当前仓库备注；
- `note clear`：清空备注。

### 4.4 hide 与 fold：对整块目录表态

面对全盘庞大的文件系统，逐仓处理往往让人疲惫不堪。人最真实的想法通常是：**“这个目录完全是噪音，我彻底不看”**，或者**“这个目录存着以前的老项目，折叠成一行知道数量就行”**。

`igit` 提供了目录级别的表态能力：

| 动作 | 含义 | 行为表现 |
|---|---|---|
| **`hide <目录>`** | 彻底屏蔽 | 全盘扫描时整树跳过，清单与树中永久消失，导出时计入免打扰资产。新放入该目录的子仓库自动继承屏蔽。 |
| **`fold <目录>`** | 概览折叠 | 照常扫描，但在清单和目录树中收拢为一行，仅展示总数与概要，绝不刷屏占地方。 |

* **相对路径就地生效**：在 `cd file:D:\repos` 作用域下，输入 `hide temp` 等价于直接屏蔽 `D:\repos\temp`。
* **随时撤销**：`unhide <目录>` 与 `unfold <目录>` 原地解除规则。
* **查看全局规则**：随时敲 `dirs` 即可总览当前设定的所有隐藏与折叠清单。

## 5. 洞察沉淀与配置管理

### 5.1 export：交互式资产大盘导出

当你完成了一轮全盘梳理，或者想沉淀一份当前机器的代码资产健康报告时：

```cmd
export
```

**你不需要记忆任何复杂的导出格式参数**：
1. 敲下 `export` 后，终端就地弹出报告复选向导，默认已勾选最核心的治理组合；
2. 直接按 `Enter` 键，系统在 0.5 秒内完成全量大盘分析与 Markdown 生成；
3. **完成瞬间，系统会自动调用 Windows 资源管理器弹窗，直接呈现在你眼前**。

导出的批次文件夹（`exports/export_YYYY-MM-DD_HHMMSS/`）包含针对不同场景定制的模块化报告：
- **`00_orphans_todo.md`**：**游离资产整理地图**。按物理父目录自动聚合尚未分组、尚未打标的仓库，按集中度排序，指引你下一步最该整理哪个目录。
- **`01_global_summary.md`**：**全局资产与健康矩阵总览**。包含脏工作区、超前/落后提交、无远端风险及分组/标签矩阵。
- **`02_global_tree.md`**：**全局层级物理目录树与绝对路径映射表**。
- **`03_scope_*.md`**：**当前作用域专属体检档案**。动态记录当前聚焦业务范围的深度报告。
- **`repos.csv` / `repos.json`**：（向导中可选勾选）带 UTF-8 BOM 的明细清单，Excel 双击即看无乱码。

### 5.2 config：交互式配置中心

同样遵循“选项交互第一”的设计，你不需要手动去翻 JSON 文件：

```cmd
config
```

终端弹出整洁的配置主菜单，按编号即可完成全部基础设置：
* **[1] 扫描根目录管理**：查看已有扫描根、输入路径添加、按编号移除；
* **[2] 报告导出设置**：开关“导出后是否自动打开文件夹”、修改默认导出目录；
* **[3] 性能与扫描深度**：配置并发协程数（Jobs）、下钻最大深度（MaxDepth）；
* **[4] 排除目录管理**：增删自动跳过的目录名（如 `node_modules`、`build`、`target`）；
* **[5] 智能探测推荐目录**：全盘轻量粗扫，按数字编号一键将高频代码目录批量加入扫描根；
* **[6] 在外部编辑器中打开**：一键在系统默认编辑器中拉起 `~/.igit/config.json` 纯文本，随心编辑保存。

## 6. 意图直达速查表（按动作意图索引）

忘掉枯燥的命令参数，根据你当下的“意图”找到对应的动词即可：

| 我的意图 | 敲什么 | 适用位置 | 交互表现 |
|---|---|---|---|
| **走进某个目录、分组或标签** | `cd <目标>` | 会话内 | 智能识别路径、`group:名` 或 `tag:名`；支持 `cd ..` / `cd -` / `cd /` |
| **看看当前位置底下有什么** | `ls` | 会话内 | 显示直属子项、所属分组、标签及 Git 脏改动与分支 |
| **看看当前所在位置与来时路** | `pwd` | 会话内 | 打印当前节点类型与完整层级栈 |
| **按标签多面漏斗检索仓库** | `lsbytag` | 会话内 | 呼出响应式标签矩阵，空格多选，回车直达仓库 |
| **查看仓库物理空间分布** | `tree` | 任意位置 | 树状骨架展开，直观查看仓库在磁盘上的聚集情况 |
| **排查全盘重复克隆** | `dupes` | 任意位置 | 停在单仓时排查该仓同源副本；全局下排查全量同源副本 |
| **审阅代码改动与提交历史** | `tig` | 任意位置 | **单仓直接敲 `tig`**，按仓库状态智能选择最佳开屏视图 |
| **在资源管理器中打开** | `open` | 任意位置 | **单仓直接敲 `open`**，直达磁盘物理目录 |
| **划定业务归属分组** | `group` | 任意位置 | 单仓下弹出分组选择菜单；目录/全局下弹出批量划分向导 |
| **添加或切换多维标签** | `tag` | 任意位置 | 单仓下弹出复选勾选面板；支持 `tag add` / `tag rm` 直通 |
| **记录一条轻量备忘** | `note <内容>` | 单仓节点 | 随手记录备忘；敲 `note clear` 清空 |
| **快速轻量提交代码** | `commit` | 单仓节点 | 就地暂存并提交，提示输入说明 |
| **免语法追加忽略规则** | `ignore add` | 单仓节点 | 提取未跟踪文件候选项，Tab 补全一键写入 `.gitignore` |
| **远端账号与 Token 管理** | `remote` | 任意位置 | 交互式配置凭证，AES-256 加密保存 |
| **快速拉取远端更新** | `fetch` / `pull` | 任意位置 | 单仓免参直通，多远端单选；冲突分叉预检拦截保护 |
| **推送到远端仓库** | `push` | 任意位置 | 多远端复选，Token 免密透传并发推送 |
| **彻底屏蔽噪音目录** | `hide <目录>` | 任意位置 | 彻底不看该目录，扫描整树跳过，新仓库自动继承 |
| **收拢折叠旧仓库目录** | `fold <目录>` | 任意位置 | 清单和树中收拢为一行概貌，不占视线 |
| **生成资产体检大盘** | `export` | 任意位置 | 交互向导确认，生成 Markdown 报告并**自动打开文件夹** |
| **调整系统配置项** | `config` | 任意位置 | 呼出配置中心菜单，一键管理扫描根与并发参数 |
